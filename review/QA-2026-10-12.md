# 키미 코드랩 로컬 검증 결과

검증일: **2026년 10월 12일**, 로컬 빌드 미리보기. 공개 배포·DNS·검색 등록·광고는 보류입니다.

## 완료

| 영역 | 결과 |
|---|---|
| 자동 검증 | 37/37 통과. QR 6종·L/M/Q/H·바이트·이스케이프·vCard 접기·URL 차단·바코드 6규격·난수 재추첨·비밀번호 조건·이미지 헤더 |
| 실제 결과물 | 브라우저에서 내려받은 PNG 12개, SVG 12개, VCF 1개 = 25개. 독립 해독기/바이트 비교로 원문 일치 |
| 브라우저 동작 | 9개 생성·계산 도구 예제 성공. QR 읽기는 실제 저장 PNG 및 합성 PNG/JPEG/WebP에서 같은 URL 복원 |
| 파일 안전 처리 | 일반 이미지 QR 없음 안내, 텍스트 파일 거부, 10MB 초과 거부, 과대 해상도 헤더 사전 거부 |
| 표시 안전 | QR의 HTML 문자열을 텍스트로 표시; DOM 삽입/실행과 자동 링크 이동 없음 |
| 레이아웃 | 390px에서 도구 10개 가로 넘침 없음. 320·768·1920px 홈 및 CODE128 80자(1910px 원본)도 페이지 넘침 없음 |
| 정적 검색 준비 | 고유 title/description, H1 1개, canonical·OG·JSON-LD, 17 HTML·16 sitemap URL·417 내부 참조 확인 |
| 헤더·외부 요청 | CSP 적용 상태에서 Worker/Blob 이미지/저장 동작. camera·microphone·geolocation 차단. 광고·분석·외부 API 코드 없음 |
| 라이선스 | qrcode·JsBarcode·jsQR·dijkstrajs 고지 포함 |

자동 검증은 SVG를 Resvg로 래스터화하고 생성 라이브러리와 별개인 jsQR/ZXing으로 읽습니다. 브라우저 PNG 저장은 실제 다운로드 파일을 pngjs로 읽어 다시 검증했습니다. VCF는 줄바꿈까지 원본 payload와 바이트 수준으로 일치합니다. HTML textarea의 표시값은 브라우저가 LF로 정리하므로 VCF 다운로드 원문을 기준으로 확인했습니다.

## 보완한 사항

- 입력/옵션 변경 즉시 기존 결과·다운로드를 무효화하고 진행 중 작업을 취소.
- QR 최소 4모듈 여백, 흰 배경·진한 색상 제한, 모듈 정수 배율 유지.
- 와이파이 특수 문자·16진수처럼 보이는 문자열 처리, 개방형에서 비밀번호 제외.
- 연락처 CRLF·UTF-8 바이트 단위 접기·필드 줄 삽입 방지.
- 바코드 체크디지트·선행 0·CODE128 앞뒤 공백 보존, SVG XML 이스케이프.
- 이미지 디코딩 전에 형식/해상도 검사, 애니메이션 PNG/WebP 차단, Worker 시간 제한.
- 인쇄 이미지 준비 후 인쇄 요청, 인쇄 종료 시 임시 DOM 제거. 일반 페이지 인쇄가 빈 화면이 되지 않도록 전용 인쇄 상태를 분리.
- 공개용 정적 HTML에 localhost 링크를 남기지 않고 로컬 검토 시에만 텍스트랩 연결 표시.
- 다운로드 이름에 입력된 비밀번호·연락처를 사용하지 않고 한국 시간 날짜 적용.

## 검증 범위의 한계 / 공개 전에 확인할 사항

- 실제 Android/iPhone 카메라 앱의 Wi-Fi 접속·연락처 추가와 물리 스캐너·인쇄물 품질은 시험하지 않았습니다. 정적 코드 데이터 복호화 성공과 해당 기기의 실제 연결 성공은 별개입니다.
- 인쇄 코드/레이아웃은 구현했고 이미지 준비·정리 로직을 검토했습니다. 실제 프린터와 PDF 출력 결과 검증은 남아 있습니다.
- 이번 브라우저 검사는 Codex 내장 Chromium 환경입니다. 실제 Safari/Firefox·모바일 OS에서 별도 확인하면 좋습니다.
- 비밀번호 생성 조건은 자동 검증했고 브라우저의 20자 표시·표시 전환·복사 완료 상태를 확인했습니다. 비밀번호를 보고서나 파일로 저장하지 않았습니다.
- 배포 호스트의 실제 `_headers`, TLS, 페이지 상태 코드, 외부 검색 수집 여부는 배포 후에만 확인할 수 있습니다.
