랜덤 비밀번호 생성기

브라우저의 암호학적 난수로 8~128자 비밀번호를 만드세요. 문자 종류를 선택하고 헷갈리는 문자를 제외할 수 있습니다.

계정마다 다른 비밀번호

길이와 대문자·소문자·숫자·기호 사용을 선택하세요. 선택한 문자 종류는 각각 최소 한 글자를 포함합니다. 0·O·1·I·l 같은 문자는 옵션으로 제외합니다. 기본 길이는 20자이며 사용하는 사이트의 길이·기호 제한을 먼저 확인하세요.

안전한 난수로 생성

Math.random 대신 Web Crypto의 getRandomValues를 사용합니다. 허용 범위를 벗어난 난수는 다시 뽑아 문자 선택의 편향을 피하고, 선택한 종류를 모두 포함하는 조건을 만족할 때만 결과를 표시합니다. 생성 결과는 저장하거나 URL에 넣지 않습니다.

복사한 뒤 비밀번호 관리자로

결과는 기본으로 가려져 있으며 사용자가 복사 버튼을 눌러야 클립보드에 들어갑니다. 클립보드 기록·기기 동기화 기능에 남을 수 있으니 공유 PC에서는 주의하세요. 생성한 값을 비밀번호 관리자로 옮기고 다중 인증을 함께 사용하세요. 화면을 닫으면 결과를 복원할 수 없습니다.

적용 형식과 참고 자료

2026년 10월 11일 구현 기준. 인식 동작은 읽는 앱과 기기에서 확인해 주세요.

자주 묻는 질문

생성된 비밀번호를 기억해 주나요?

아닙니다. 서버와 브라우저 저장소에 저장하지 않습니다. 새로 생성하거나 페이지를 닫으면 이전 값을 되찾을 수 없습니다.

무조건 안전한가요?

암호학적 난수를 사용하지만 계정 보안은 피싱 방지·기기 보안·재사용 방지·다중 인증에도 달려 있습니다.
