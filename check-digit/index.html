바코드 체크디지트 계산·검증

EAN13·EAN8·UPC-A·ITF14 마지막 숫자를 계산하거나 검증하세요. 상품 식별번호의 입력 오류를 확인합니다.

마지막 한 자리의 의미

체크디지트는 앞의 숫자에 3과 1의 가중치를 번갈아 적용한 합이 10의 배수가 되도록 정합니다. 이 도구는 EAN13 12+1자리, EAN8 7+1자리, UPC-A 11+1자리, ITF14 13+1자리를 지원합니다.

입력 방법

마지막 숫자를 제외한 본문을 넣으면 완성 번호를 계산하고, 전체 번호를 넣으면 체크디지트를 검증합니다. 숫자는 문자열로 처리하므로 맨 앞의 0도 유지됩니다. 공백이나 하이픈으로 숫자를 나누지 말고 연속해서 입력하세요.

일치해도 정식 상품번호는 아닐 수 있습니다

체크디지트가 맞는 것은 산술적인 형식이 맞는다는 뜻입니다. 상품 정보, 등록 회사, 중복 여부나 번호 사용 권한을 보증하지 않습니다. 생성한 번호는 실제 유통 요건을 별도로 확인하세요.

규격별 입력 기준

마지막 숫자는 상품번호의 체크디지트입니다

자주 묻는 질문

오류가 있으면 자동 수정하나요?

틀린 전체 번호는 유효한 번호로 표시하지 않고 예상 마지막 숫자를 안내합니다. 사용자가 원본을 확인한 뒤 수정해야 합니다.

카드번호도 검사하나요?

아닙니다. 이 도구는 GS1 계열 상품번호의 체크디지트만 지원합니다.
